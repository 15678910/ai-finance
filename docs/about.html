이것은 무엇인가

공개된 통계와 시장 데이터를 자동으로 모아 규칙에 따라 계산한 결과를 보여주는 개인 프로젝트입니다. 코드와 계산식은 전부 공개돼 있어 누구나 검증할 수 있습니다.

  • 금융 대시보드 — 지수·환율·금리·통화량 등의 추세와 상관관계
  • 내 실질임금 · 임금단협 · 노동 양극화 해소 계산기 — 체감물가, 회사 지불능력, 임금격차와 해소 경로
이것이 아닌 것
  • 투자자문이 아닙니다. 특정 종목의 매수·매도를 권하지 않으며, 개인의 사정에 맞춘 조언도 하지 않습니다. 작성자는 금융투자업 인가를 받은 사업자가 아닙니다.
  • 노무·법률 자문이 아닙니다. 임금단협 계산기는 공개 공시와 사용자가 넣은 값으로 산술 계산을 할 뿐입니다. 교섭의무의 범위, 파견·도급의 구분, 직접고용 의무 같은 판단은 법률 영역이며 공인노무사·변호사의 확인이 필요합니다.
  • 공식 통계가 아닙니다. 원 자료를 가공한 2차 산출물입니다. 공식 수치가 필요하면 아래 출처의 원문을 인용하세요.
  • 어느 쪽 주장도 대변하지 않습니다. 노동측·사측 어느 편의 근거로도 쓰일 수 있도록 양쪽 지표를 같은 화면에 놓았습니다.

계산 결과를 협상·보고 자료로 쓸 때

  • 산출 근거(어떤 값을 넣었고 어떤 식으로 계산했는지)를 반드시 함께 제시하세요. 근거 없이 숫자만 내면 "조작했다"는 반박을 받습니다.
  • 공시에서 자동으로 가져온 값은 원문 사업보고서로 교차 확인하세요. 연결/별도 기준, 급여 포함 범위가 회사마다 다를 수 있습니다.
  • 사용자가 직접 넣는 값(고용형태별 급여, 간접고용 인원·도급비 등)은 출처를 밝혀야 자료로서 효력이 있습니다.

개인정보 — 수집하지 않습니다

이 사이트는 서버가 없습니다. 정적 파일만 제공하는 GitHub Pages 위에서 동작하며, 회원가입도 로그인도 없습니다.

다만 GitHub Pages를 운영하는 GitHub이 접속 로그(IP·시각 등)를 자체적으로 기록할 수 있습니다. 이는 이 사이트가 제어할 수 없는 영역이며, GitHub 개인정보처리방침을 따릅니다. 별도의 분석 도구(Google Analytics 등)나 광고·추적 스크립트는 넣지 않았습니다.

계산의 한계 — 알고 쓰셔야 할 것

체감물가

  • 공식 소비자물가는 대출이자와 자가주거비를 포함하지 않습니다. 국제 기준(COICOP)상 이자는 소비가 아니라 금융거래로 분류되기 때문입니다. 그래서 이 계산기에 직접 넣는 칸을 따로 두었습니다.
  • 공식 물가는 '없던 지출이 새로 생긴 것'을 재지 않습니다(AI 구독료 등). 이것도 별도 입력 항목입니다.
  • CSV 자동 분류는 가맹점명 키워드 기반이라 완벽하지 않습니다. 결과를 확인하고 조정하세요.

임금·격차

  • DART는 고용형태별 급여를 공시하지 않습니다. 인원만 정규직·기간제로 나뉘고 급여는 합산입니다. 따라서 형태별 임금 격차는 사용자 입력값에 전적으로 의존합니다.
  • 사내하도급·파견·용역 인력은 어떤 공시에도 없습니다. 직접 넣어야 하며 그 정확도가 결과를 좌우합니다.
  • '실질' 지표(간접고용 포함 재계산)는 회계 기준이 아닙니다. 회사 공식 재무제표와 다른 값이므로 산출 근거를 반드시 밝히세요.
  • 근속·직무·근무지가 다르면 평균 비교만으로 '동일가치노동'을 단정할 수 없습니다.
  • 소요 연수는 인상률이 매년 일정하다고 본 값입니다. 실제로는 물가·실적에 따라 달라집니다.

추세·예측

  • 상관관계는 인과가 아닙니다. 통화량과 물가의 관계도 시대에 따라 부호가 뒤집힙니다 (QE 시기에는 역상관이었습니다).
  • 예측 지표는 과거 데이터로 만든 통계적 추정이며, 맞은 기록과 틀린 기록을 함께 공개합니다.
